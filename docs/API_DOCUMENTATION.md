# API documentation

Protected routes: `GET/POST/PATCH/DELETE /api/v1/conversations`, `GET /api/v1/conversations/{id}`, `POST /api/v1/chat/message`, `GET /api/v1/memory`, `DELETE /api/v1/memory/{id}`, `GET /api/v1/rooms`, `GET /api/v1/rooms/{id}`, and `POST /api/v1/availability/search`. `GET /health` is public. All protected routes require `Authorization: Bearer <Supabase access token>`.
